# InfusionCalc v0.1.5

Stabilne wydanie naprawcze kompletności lokalnego pakietu fontów Flutter Web. Usuwa powtarzające się odpowiedzi HTTP 404 dla `Noto Sans Symbols` widoczne m.in. w konsoli Firefoxa i zachowuje pełne działanie PWA offline.

## Poprawiono

- do produkcyjnego artefaktu dodano dokładnie ten wariant `Noto Sans Symbols v43`, którego żąda silnik Flutter Web;
- font jest pobierany podczas buildu z przypiętego adresu i sprawdzany przez rozmiar, sygnaturę WOFF2 oraz SHA-256;
- lokalny katalog `fallback-fonts/` zawiera teraz zarówno Roboto Regular, jak i Noto Sans Symbols;
- kopia licencji SIL Open Font License 1.1 dla Noto Sans Symbols jest publikowana razem z aplikacją;
- finalizer odrzuca build, jeżeli brakuje któregokolwiek fontu albo odpowiadającej mu licencji;
- oba fonty są częścią `offline-manifest.json` oraz wersjonowanego cache service workera.

## Testy i wdrożenie

- dodano deterministyczne testy rozmiaru, sygnatury, SHA-256, atomowego pobierania i kompletności licencji;
- CI, GitHub Pages i archiwalny build mini-PC wymagają obecności obu dokładnych ścieżek fontów;
- build nadal używa `--no-web-resources-cdn` i pozostaje samowystarczalny po jednorazowym uruchomieniu online;
- publikacja GitHub Pages nadal przechodzi test uruchomienia online → całkowicie offline.

## Granice wydania

- brak zmian w solverze, równaniach, jednostkach, precyzji i danych formularza;
- brak zmian w wyglądzie lub sposobie obsługi kalkulatora;
- brak nowych trackerów, reklam, cookies marketingowych i identyfikatorów użytkownika;
- InfusionCalc pozostaje technicznym kalkulatorem matematycznym, a wynik wymaga niezależnej weryfikacji.
