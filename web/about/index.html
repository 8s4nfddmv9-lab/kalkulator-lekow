Free browser-based PWA

Technical infusion calculations, without a setup screen.

InfusionCalc is a bidirectional calculator for drug amount, solution volume, concentration, infusion flow and dose. The main address opens the calculator immediately, while this page explains what the tool does and where its limits are.

Capabilities

Start with the values you already know

Bidirectional calculations

Enter any supported combination of values. InfusionCalc solves the remaining fields without a separate “dose-to-rate” or “rate-to-dose” mode.

Explicit units

Mass units and IU are kept dimensionally separate. Dose can be expressed with or without /kg, per minute or per hour.

Offline after preparation

The installable PWA stores one complete, versioned application bundle after a successful online launch, so the calculator can start without a network connection.

Supported values

A compact set of technical infusion parameters

  • drug amount: ng, µg, mg, g
  • biological activity: IU
  • solution volume: ml
  • concentration
  • flow: ml/h
  • dose: per min or per h
  • optional /kg
  • patient mass: g or kg

Product design

Fast access remains the priority

No landing page before the calculator

Opening infusioncalc.eu takes the user directly to the working calculator. Informational content remains on separate static pages.

Local calculations and minimal analytics

Form values and results are processed locally. The public website uses limited Umami page and interface analytics that do not receive calculator values.

Important limits

A mathematical tool, not a dosing reference

InfusionCalc does not provide drug libraries, dose ranges, recommendations or clinical interpretation. It is not intended to make clinical decisions. Inputs, units and results require independent verification before any clinical use.

The open-source code, calculation model and technical documentation are available in the project repository.

FAQ

Common questions

Does it work on iPhone and Android?

Yes. It runs in modern browsers and can be added to the home screen as a PWA. Platform support still depends on the browser and operating system.

Are calculator values uploaded?

No application code sends mass, amount, concentration, flow, dose, formulas or results to analytics. See the privacy page for the full contract.

Does first use require internet?

Yes. The first launch and every new version must complete online before that version is available offline.

Where can changes be reviewed?

The concise public history is on the changelog page, with the full versioned record in the GitHub repository.
